# Glossary

Terms used throughout the codebase, story format, and docs.

---

| Term | Definition |
|---|---|
| **Node** | A single scene or moment in a story. Has `text`, `choices`, and optional `insets`/`overlays`. Identified by a string key in the `nodes` dict. |
| **Choice** | A player decision attached to a node. Has a `label`, points to a `next` node ID. Can `require` flags and `set` flags when taken. |
| **Flag** | A named value in `Engine._state`. Set by `choice.sets`; checked by `requires`. Types: `bool`, `int`, or `str`. |
| **State** | The full dict of flags for the current run. Persisted in the save file; cleared on reset. |
| **Overlay** | Conditional text displayed around the choice list (`before` = above choices, `after` = below). Filtered by Engine before Display. On ending nodes, all overlays appear before the ending panel. |
| **Inset** | Styled text inside the story panel, separated by a dim rule. Appears `before` or `after` the main prose. Not valid on ending nodes — use overlays instead. |
| **Ending** | A terminal node. Has `is_ending: true` or an empty `choices` array. Triggers the ending screen and save deletion. |
| **Ending type** | `good`, `bad`, or `neutral`. Controls ending panel colour (green, red, yellow). |
| **Gallery** | Per-story record of found ending node IDs. Stored in `saves/<story_id>.gallery.json`. Persists across runs; survives active save deletion. |
| **Save** | Active game state: `current_node`, `history`, `state`, `timestamp`. One slot per story at `saves/<story_id>.save.json`. |
| **History** | Breadcrumb list of visited node IDs in the current run. Preserved in the save file for future features. |
| **Scene** | Optional location label on a node (`"scene": "The Library"`). Renders as a dim Rule above the story panel. Carries forward to subsequent nodes until a new `scene` key overrides it. |
| **Requires** | Condition dict checked against flag state. Hides choices, overlays, or insets when conditions are not met. Supports bool match (a never-set flag counts as false), int threshold (≥), string exact match, list membership. |
| **Sets** | Flags applied to `_state` when a choice is taken. Supports `bool`, `int`, `str`, and delta strings (`"+1"`, `"-2"`). |
| **Visited flag** | Auto-set flag `visited_<node_id>` each time a node is entered (when `meta.auto_visited_flags` is true). The `visited_` prefix is reserved. |
| **Inline conditional** | `{flag?shown if true\|shown if false}` span embedded in any text field. False branch is optional. Resolved at runtime against current flag state. |
| **Pause token** | `{pause}` embedded in node/ending text. Injects a `typewriter.pause_ms` delay mid-stream during typewriter playback. Stripped silently in non-typewriter mode. |
| **Typewriter** | Character-by-character animation of prose text in CLI and web player. Configurable; skippable with any keypress. |
| **Reader mode** | Accessible mode: light paper theme, Newsreader font, semantic HTML, no animation, button-driven navigation. |
| **Terminal mode** | Default web rendering: dark terminal aesthetic, typewriter animation, keyboard navigation. |
| **Story manifest** | `web/stories.json` — static list of stories for the web player. Generated by `scripts/sync_stories.py`; must be committed after changes. |
| **Variable Text Substitution** | `{key}` placeholders in any text field replaced at runtime with `str(state[key])`. Missing keys leave the placeholder intact. Runs before conditional inline resolution. Applies to node text, insets, and overlays in both Python and JS engines. |
| **Protagonist name prompt** | Optional pre-game screen declared via `meta.name_prompt`. Asks the player for a name, stores it as `player_name` in engine state, and makes it available as `{player_name}` in any text field via Variable Text Substitution. Asked at every fresh run (first launch, New game, play again); skipped when resuming a save. |
| **`player_name`** | Reserved state key for the player's chosen protagonist name. Set by the name prompt (if the story declares one) before the first node. Authors use `{player_name}` in story text; the engine's default value in settings is `"Felix"`. |
| **Client variable** | A player-provided value (not set by story choices) that persists across stories via `settings.json`. `player_name` is the first client variable. |
| **Fresh run** | A run that starts from the story's beginning rather than from a save: first launch with no save, "New game" at the resume prompt, or play again after an ending. |
| **`fresh_run_state`** | Optional `Engine` constructor argument — a host-supplied callable invoked at every fresh run that returns the seed-state dict, or `None` to abort back to the picker. `main.py` supplies one that runs the protagonist name prompt. Its result replaces `initial_state`. |
| **Corrupted span** | A `{corrupt:intensity:mode}…{/corrupt}` inline token in any text field that marks a region for glitch rendering. Resolved by the engine into a `CorruptedSpan` object; rendered by Display as static glitch characters or a typewriter scramble-settle animation. |
| **CorruptedSpan** | Engine data model for a single corruption region: original text, effective intensity (author × global multiplier), mode (`consistent`/`random`), and a deterministic seed for consistent mode. |
| **TextSegments** | `list[str \| CorruptedSpan]` — the output of `_resolve_corruption()`. Plain string segments interleave with `CorruptedSpan` objects. Passed to Display in place of a plain `str` for node text, insets, and overlays. |
| **Corruption intensity** | Float 0.0–1.0 controlling what fraction of non-space, non-punctuation characters are replaced with glitch characters. Author-set per span or node; if unset anywhere in the story, falls back to the player's **Intensity Default** setting — either way, the player's **Intensity Multiplier** always applies on top. |
| **resolve_style** | Optional 4th positional param on a `{corrupt}` span (`decay` or `cascade`), or a key on the node `corruption` field. When set, the span types in corrupted (as normal), then a second typewriter phase settles it back into its original clean text — `decay` via a shrinking-intensity re-corruption, `cascade` via a character-by-character reveal. No global settings default; opt-in per span/node only. |
| **Intensity Default** | Settings-screen label for `corruption.intensity` — the fallback intensity used only when neither a span nor its node specifies one. A story-defined intensity fully overrides this rather than multiplying with it (same pattern as **Mode Default**). |
| **Intensity Multiplier** | Settings-screen label for `corruption.intensity_multiplier` — an always-applied accessibility scalar layered on top of whichever intensity wins (story value or Intensity Default). The one corruption setting that is not a "Default" — it always applies, never a fallback. |
| **Mode Default** | Settings-screen label for `corruption.mode` — the fallback mode used only when neither a span nor its node specifies one; same override-or-default behavior as Intensity Default. |
| **SETTINGS_SECTIONS** | Registry data structure (Python list / JS array) that is the single source of truth for all settings on each platform. Each entry declares an `id`, `label`, `preserve_on_global_reset` flag, `has_subscreen` flag, `config_keys`, and `rows`. Settings rendering, sub-screen navigation, and reset logic all derive from it. |
| **Section subscreen** | A generic settings sub-screen rendered from `SETTINGS_SECTIONS` row descriptors — no section-specific code. Nav keys: S (save+back), X (discard section+back), M (save+home), Q (discard all+home), R (reset section). |
| **Reset to defaults** | Feature activated by `R` on the main settings screen. Shows a checkbox selector listing resettable sections; `Y` applies `apply_section_defaults` / `applyDefaults` for each checked section. `player_name` and `accessible_mode` are always preserved. |
| **Setting range** | The `(lo, hi)` bound on a numeric settings row: the `range` key in Python's `SETTINGS_SECTIONS`, mirrored by `SETTING_RANGES` in `web/engine.js`. Enforced when a value is typed and again when it is used (`clamp_setting`, `clampSetting`); a parity test keeps the two tables identical. |
| **Saga** | A group of chapters sharing `meta.saga_id`, forming a directed graph linked by ending-node `next_story` edges. Shown as one row in the story picker that opens the saga home screen. |
| **Chapter** | A regular story JSON file that belongs to a saga (`meta.saga_id`). Still a valid story file on its own; hidden from the picker except through its saga. |
| **Entry chapter** | The one chapter of a saga that no other chapter's `next_story` targets. Carries `meta.saga_title` and is always listed on the saga home screen. |
| **Chapter-entry seed** | `saves/<chapter_id>.handoff.json` — the exported flags (plus `player_name`) a chapter starts with. Persists until a parent chapter chains into it again or all save data is cleared, so New game and replay re-seed from it in any session. |
| **Exports** | The `exports` list on a chaining ending node: exact flag names (including `visited_<node>`) that carry into the next chapter under their original names. No wildcards. |
| **Chapter transition** | `chapter_transition: true` on a chaining ending node: the node renders as a normal story panel plus one continue keypress instead of the ending screen and prompt. |
| **Saga end** | `saga_end: true` on an ending node: marks the saga's true finale ("End of saga"); mutually exclusive with `next_story`. A saga counts as complete once any `saga_end` node is in a chapter's gallery. |
| **Saga home screen** | The screen opened by selecting a saga row: lists reached chapters plus a "…more to discover" hint, and is where chapter replay lives. |
| **Reached / active chapter** | Reached: the chapter currently has a seed or an active save (the entry chapter is always listed). Active: it has an active save or a pending seed. |
| **Seed (disambiguation)** | Four unrelated meanings: the chapter-entry seed (`saves/<id>.handoff.json`), the `--seed` / `?seed=` author override, a corruption span's deterministic `seed`, and `fresh_run_state`'s "seed state". |
| **StoryLoader** | `src/story.py` — discovers `.json` files in `/stories/`, parses them into data models, and validates them. Raises `StoryValidationError` on any structural problem. |
| **Engine** | `src/engine.py` — the only coordinator. Runs the game loop, maintains `_state`, calls `Display` methods, and drives `SaveManager` and `GalleryManager`. |
| **Display** | `src/display.py` — all `rich` rendering. Purely passive: renders what it's given, prompts for input, re-prompts on invalid input. No game state knowledge. |
| **Skill-token audit** | `scripts/audit_skill_tokens.py` — scans this project's own Claude Code transcript history to measure whether exploration-tooling guidance in CLAUDE.md is changing agent tool-use behavior. Read-only against `~/.claude/projects/`; writes only its own baseline snapshot. |
| **Baseline snapshot** | `docs/projectmanagement/skill-token-baseline.json` — the skill-token audit's saved reference point (Read:semble ratio, Read's share of exploration tokens, fruitless Grep/Glob rate, true-duplicate Reads). Every audit run after the first prints a delta against it instead of overwriting it. |
